# Changelog

## [v0.1.0]

Initial release.

- Open folders in MSL distributions from VS Code, VS Code Insiders, VSCodium or Cursor.
- Connect through MSL's managed pipes and vsock, without an SSH server or a TCP port on the Mac.
- Install the matching VS Code Server from the Mac and cache it for reuse; the distro does not need `curl` or `wget`.
- The release publishes `msl-0.1.0.vsix` and its SHA-256 checksum.
